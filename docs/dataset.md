# Dataset settings (v4.9, used for training; v4.7 for comparison)

Simulated construction-site dataset generated by Insu Jeon in Isaac Lab. It is stored on the Hugging Face Hub
(`world-nav/world-nav`, sub-folders per version). Access is private for now and may be opened later.
Values that differ between the two versions are in **bold**.

## 1. Summary

| | v4.7 (midterm) | v4.9 (current) |
|---|---|---|
| Episodes | 500 (seeds 10000–10499) | 500 (seeds 70000–70499) |
| Samples (10 Hz) | 192,280 (185,292 with valid labels) | 155,065 (148,152 with valid labels) |
| Behaviours | expert, naive, intruder, random | **+ bystander** |
| Counterfactual branches | none | **4,463 points × 7 commands × 3 s** |
| Labels | danger_H etc. | **+ time_to_danger_s, far_now, anticipation_H** |
| Wheel loader overlapping the truck | 15 of 88 episodes | **0 (fixed)** |
| Danger samples | 20.5 % | 18.7 % |
| Samples with every machine > 2 m away / danger among them | 75.6 % / 4.3 % | 79.0 % / 5.7 % |

## 2. Common settings

| Item | Value |
|---|---|
| Simulator | Isaac Lab 3.0 / Isaac Sim 6.0.1, PhysX, flat ground |
| Robot | Unitree Go2 with Isaac Lab's pretrained walking policy (RSL-RL PPO, `Isaac-Velocity-Flat-Unitree-Go2`); the behaviours only send velocity commands (vx, vy, wz) |
| Rates | physics 50 Hz, recording 10 Hz |
| Machines | kinematic models following scripted work cycles |
| Command limits | linear acceleration 1.0 m/s², yaw acceleration 2.0 rad/s², max yaw rate 0.7 rad/s (the walking policy falls above ~0.9) |
| Keep-alive | after 2 s of standing still, a 0.2 rad/s wiggle (the walking policy tends to tip over when standing) |
| Unstuck | if the robot moves less than 0.15 m / 0.3 rad in 4 s while commanded, 1.5 s straight at 0.4 m/s |

| Max length random | 60 s | 60 s |

| Termination | Condition | v4.7 | v4.9 |
|---|---|---|---|
| goal_reached | within 0.6 m of the goal | 165 | 118 |

The extra falls in v4.9 come from the strafe and uniform commands of the random behaviour (45 of 125 random episodes).

## 4. Behaviours

| Behaviour | What it does | v4.7 | v4.9 |
|---|---|---|---|
| expert | knows the machine positions, waits or detours | 10 % | 10 % |
| naive | ignores machines, goes straight to the goal | **25 %** | **20 %** |
| intruder | walks into the working area on purpose (stays 3–10 s) | **40 %** | **25 %** |
| random | random commands held 0.5–1 s | 25 % | 25 % |
| bystander | stands or moves slowly while a machine comes towards it | – | **20 %** |

- Speeds: expert 0.5–0.9 m/s, naive 0.6–1.0 m/s, intruder 0.5–0.9 m/s.
- Bystander (v4.9): 50 % stand still, the rest move at 0.1–0.25 m/s; placed 3–8 m from where a machine part
  (body, truck, excavator arm or bucket) will pass 6–18 s later, facing it ± 0.8 rad.
- Noise (expert and naive only): OU noise on the command (vx σ 0.15, wz σ 0.35, τ 1 s, per-episode scale 0–1), plus
  random commands injected **0.3/s (v4.7) → 0.5/s (v4.9)**, held 0.5–1 s.

### Random behaviour command mix

| Command | v4.7 | v4.9 | Value |
|---|---|---|---|
| forward | **30 %** | **20 %** | 0.3–0.9 m/s |
| turn left / right | **17.5 / 17.5 %** | **13 / 13 %** | 0.3 m/s ± 0.5 rad/s |
| wait | **17.5 %** | **13 %** | 0 |
| backward | **17.5 %** | **13 %** | −0.3 m/s |
| strafe left / right | **–** | **7 / 7 %** | ± 0.25 m/s |
| uniform | **–** | **14 %** | vx −0.3–0.9, vy ± 0.25, wz ± 0.6 |

Executed commands in the main trajectories (nearest primitive) are almost the same in both versions
(forward 76–80 %, turns 9 %, wait 7–8 %, backward 4 %, strafe 0 → 4 %); most of the command diversity of v4.9 comes
from the branches.

## 5. Counterfactual branches (v4.9 only)

The simulator is rewound to the same moment and each of 7 commands is executed for 3 s; everything (frames, poses,
clearances, contacts) is recorded.

| Item | Value |
|---|---|
| Commands | forward 0.7, turn left (0.3, +0.5 rad/s), turn right (0.3, −0.5), wait, backward −0.3, strafe left +0.25, strafe right −0.25 |
| Length | 3 s each (30 frames at 10 Hz) |
| Triggers | machine within 0.5–5 m / a machine within 8 m approaching faster than 0.5 m/s / prop within 0.3–2.5 m |
| Spacing | from t = 2 s, at least 2 s between branch points |
| Result | 4,463 points (machine near 3,257, machine approaching 610, prop near 596) |

## 6. Randomisation (both versions)

| Target | Range |
|---|---|
| Sky | clear 50 % / overcast 35 % / low sun 15 %, 10 HDR skies, exposure 700–1300 |
| Light | sun on 75 %, intensity 1000–2500, elevation 20–75° (low sun 5–15°), 4500–6500 K (low sun 3200–4500 K), dome 500–1400 |
| Ground | 7 base materials, texture scale 0.15–0.4, 3–8 patches of other materials (3–14 m) |
| Props | 8–16 of 9 types (concrete block, pallet, pipe, rebar, rock, cone, barricade, drum, crate), 35 % on the naive route |
| Machine size | excavator 0.75–1.2×, truck 5.5–8.5 m long, 2.3–2.6 m wide, 2.4–3.2 m high; loader / dozer / roller 0.85–1.15× |
| Layout | stockpile 6.5–8 m away, radius 1.8–2.6 m; truck parking 6.5–7.5 m; start and goal 1–8 m outside the working area |
| Excavator motion | operator speed 0.8–1.2×, joint pose jitter, idle probability 10–12 % |
| Trucks | forward 2–3.5 m/s, reverse 0.8–1.3 m/s, 3–5 loads per truck, next truck after 5–20 s |

Scenarios (excavator_loading 30 %, the others 17.5 % each):

| Scenario | Main random values |
|---|---|
| excavator_loading | excavator + dump-truck loading cycle (above) |
| wheel_loader | forward 1.5–2.8 m/s, reverse 1.2–2.2 m/s, dig 1.5–3.5 s, dump 1.5–3 s |
| dozer | push 0.7–1.4 m/s, reverse 1.4–2.4 m/s, push length 10–18 m, 2–4 lanes |
| haul_road | road 7–9 m wide, 2–4 trucks at 3–7 m/s every 4–25 s, travelling excavator 0.5–1.1 m/s |
| pit_roller | pit 4–7 × 3–5 m, 1.5–3 m deep, roller 1–2 m/s, 2–4 passes |

## 7. Labels (`labels_h3_m1.jsonl`, every 10 Hz sample)

| Label | Definition | v4.7 | v4.9 |
|---|---|---|---|
| danger_H | machine contact within the next 3 s, or any machine part within 1 m | ✓ | ✓ |
| clearance_now / min_H, nearest_part | current clearance, minimum over 3 s, closest part | ✓ | ✓ |
| contact_H, envelope_hit_H | machine contact, excavator arm sweep | ✓ | ✓ |
| prop_contact_H, clearance_prop | prop contact, prop clearance | ✓ | ✓ |
| pit_H | falling into the pit | ✓ | ✓ |
| time_to_danger_s | time until the next danger (up to 10 s, else null) | – | ✓ |
| far_now | every machine more than 2 m away | – | ✓ |
| anticipation_H | danger_H while far_now (danger that has to be anticipated) | – | ✓ |

The last 3 s of each episode have no future and are marked `valid = false`.
